## 📌 Click Counter Web App

A simple yet powerful **Click Counter Web Application** designed to track, manage, and customize your click activities with ease. This project emphasizes usability, flexibility, and a clean user experience, making it suitable for both casual users and productivity-focused tasks.

---
**Live link:** https://sanzidahmed4.github.io/ClickCounter/

## 🚀 Key Features

* 🎨 **Customizable Theme** – Easily switch themes to match your personal preference.
* 🌈 **Custom Color Picker** – Apply fully customized colors for a personalized UI experience.
* 📊 **Click History Tracking** – Access and review your click history anytime.
* 🔢 **Manual Click Adjustment** – Set the counter to any desired value instantly.
* ➖ **Click Decrement Option** – Reduce the click count whenever necessary.
* 💾 **Session Persistence** – Your data remains saved and will not reset unless you close the browser/tab or manually clear the counter.
